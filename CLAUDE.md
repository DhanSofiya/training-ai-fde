# CLAUDE.md

This repository contains weekly coursework for the AI Fundamentals for Developers (AI FDE) program under K-Youth. It is organised into thirteen weekly folders (week-00 through week-12), each containing code, notes, and deliverables for that week. The root README serves as an index linking to each week folder.

## How to work with me

### Explanations

- Be concise but always step-by-step.
- Assume I have no prior knowledge on the topic.
- Be direct — always specify *where* something needs to be done (which file, which panel, which command).
- Number every step and every checklist item so I can refer to them by number.

### Code style

- Write beginner-friendly code: simple logic, short functions, easy to read at a glance.
- No complex abstractions or patterns unless the task specifically requires it.

### Corrections

- If I make a mistake or misunderstand something, ask me to reconsider before giving the answer.
- Do not just silently fix it — help me think it through first.

## Hard rules

1. Never commit API keys, secrets, or credentials — they live in environment variables only.
2. Always number checklists and step-by-step instructions.
3. Always ask before creating new files in this repo.
4. Always run and verify code before committing.
5. Always ask for clarification before starting complex or ambiguous tasks — do not assume.
