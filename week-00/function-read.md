# Function Read

## The function

```python
def divide(a, b):
    return a / b
```

## What it does

Takes two numbers and returns the division result.

## What would break it

- If either `a` or `b` is not given, it will break.
- If `b` is 0, it will break.
- If `a` or `b` is not a number, it will break.
